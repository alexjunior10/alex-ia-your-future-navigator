__ALEX IA — QUESTION BANK V1__

*Banco de preguntas para el Test ADN Vocacional · QBANK\_V1*

Propósito: convertir el Blueprint 38×Evidencia V1 en un primer banco concreto de preguntas para estudiantes de 13–19 años\. \[NOTA DE GOBERNANZA OFICIAL: La fuente operativa y vinculante de scoring es Question\_Option\_Variable\_Matrix\_V1\_1\.xlsx\. En caso de cualquier discrepancia, prevalece la Matriz V1\.1\.\] Este documento es de diseño y validación; todavía no constituye el scoring psicométrico definitivo ni debe implementarse en producción sin pilotaje\.

# 1\. Reglas de diseño

- Las preguntas buscan evidencia de intereses, aptitudes, personalidad, valores y preferencias sin nombrar directamente el constructo\.
- Una pregunta puede aportar evidencia primaria y secundaria a varias variables\.
- Los constructos cercanos se mantienen separados: interés ≠ capacidad ≠ comodidad ≠ valor/preferencia\.
- Las preguntas de aptitud miden desempeño en el propio ítem cuando corresponde; no se sustituyen por autopercepción\.
- Las alternativas deben ser plausibles y no depender de salario, prestigio, popularidad o conocimiento previo de carreras\.
- La escala de evidencia propuesta en esta versión es provisional: \-2, \-1, 0, \+1, \+2\. No es todavía el score 0–100 del ADN\.
- Se recomienda permitir 'No estoy seguro/a' solo donde no distorsione una tarea de desempeño; debe registrarse como respuesta de baja evidencia, no como respuesta incorrecta\.
- La batería final deberá conservar una combinación de situaciones, elecciones forzadas, preferencias y mini\-retos\.

# 3\. Escala provisional de evidencia

Para el prototipo de banco se utiliza una escala direccional, no el score final del ADN: \+2 evidencia fuerte a favor de la variable; \+1 evidencia moderada; 0 evidencia neutra/mixta; \-1 evidencia moderada en sentido contrario; \-2 evidencia fuerte en sentido contrario\. En preguntas de aptitud objetiva, el resultado puede transformarse posteriormente mediante una regla específica\.

# 6\. Lo que todavía NO está definido

- No está definido el algoritmo definitivo que transforma respuestas en scores 0–100 para las 38 variables\.
- No se ha definido si todas las preguntas tendrán el mismo peso o si algunas tendrán mayor poder discriminativo\.
- No se ha calibrado la dificultad de los mini\-retos por edad/grado escolar\.
- No se ha probado la duración real con estudiantes de 13–19 años\.
- No se ha validado todavía si las alternativas producen perfiles suficientemente diferenciados\.
- No se debe conectar todavía el resultado de cada respuesta directamente a una carrera: primero debe construirse el perfil de 38 variables y luego ejecutar MATCHING\_V1\.
- Las Discovery Signals del onboarding siguen siendo complementarias y no sustituyen este banco\.

# 7\. Próximo paso metodológico

Antes de Antigravity, el siguiente artefacto debería ser SCORE MODEL V1: definir exactamente cómo cada respuesta genera evidencia por variable, cómo se agregan múltiples preguntas, cómo se normalizan las variables, cómo se tratan 'No sé', respuestas inconsistentes y perfiles planos, y cómo se transforma el perfil final al formato 0–100 que consume MATCHING\_V1\. Después de eso se realiza un piloto pequeño y recién entonces Calibration V2 con perfiles generados por estudiantes reales\.
